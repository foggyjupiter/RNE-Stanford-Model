## Static files

- `read_resistance.csv` — `x_m,w_m,R_ohm`: cell resistance at a 0.2 V read (includes RL, RH; Rs = 0)
- `fixed_state_iv.csv` — `x_m,A_m2,v_V,i_A`: fixed-state mode I-V (x, A_CF given)
- `filament_current.csv` — `v_V,x_m,w_m,i_A,v_gap_V`: single-filament current (eqs. 6–7 in series) on a grid with no parasitics. Unit test for the core function.
