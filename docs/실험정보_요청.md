# 시뮬레이션·역산에 필요한 실험 정보

시뮬레이터에 실험 소자를 넣고, 측정 I-V에서 필라멘트 굵기·개수와 갭 크기를 역산하는 데 필요한 정보입니다. ★는 꼭 필요한 항목이고, 나머지는 있으면 결과가 더 정확해지는 항목입니다.

## 1. 소자 구조

| | 항목 | 쓰는 곳 |
|---|---|---|
| ★ | 적층 구조와 재료 (예: TiN / HfO₂ / TiN). 스위칭 산화막 종류와 증착 방법 | 산화막·필라멘트 물성 문헌값 선택 |
| ★ | 산화막 두께 (nm) | 필라멘트 길이 |
| ★ | 셀 면적 또는 전극 크기. 여러 크기가 있으면 모두 | 필라멘트 밀도, 산화막 비저항 |
| ★ | 위·아래 TiN 전극 두께와 증착 방법 (스퍼터 / ALD) | 전극 열 배출. TiN 열전도도는 방법에 따라 7–27 W/(K·m) |
| | 기판과 주변 절연막 (예: Si / SiO₂) | 열이 빠지는 경로 |

## 2. 측정 조건

| | 항목 | 쓰는 곳 |
|---|---|---|
| ★ | 측정 장비(SMU 모델), 계단 크기(0.1 V), **계단당 머무는 시간** 또는 스윕 전체 시간 | 램프 속도 → RESET·SET 전압에 직접 영향 |
| ★ | SET 전류 제한 값 (1e-5 A 맞는지), RESET 때 전류 제한 값 (0.1 A 맞는지) | 시뮬레이션 조건 |
| ★ | RESET 측정을 멈추는 기준 (전류가 몇 분의 1로 떨어지면 멈추는지) | RESET 점 정의 |
| | Forming 전압과 Forming 때 전류 제한 값 | 초기 필라멘트 굵기 |
| | 측정한 사이클 수, 소자 수 | 통계(산포) |
| | 프로브·배선 저항 | 직렬 저항 R_L 보정 |

## 3. 데이터 (CSV)

형식: `sweep, op, v_V, i_A, rate_Vps, icc_A` (op = forming / set / reset, 스윕마다 측정 순서대로). 엑셀에서 열만 맞춰 주면 됩니다.

| | 데이터 | 쓰는 곳 |
|---|---|---|
| ★ | Forming I-V 1개 이상 | 포밍 전 누설 전류 → 산화막 비저항 |
| ★ | RESET I-V 여러 사이클 | LRS 저항, RESET 전압·전류, 필라멘트 온도·열저항 → 필라멘트 굵기·개수 |
| ★ | SET I-V 여러 사이클 | HRS 저항 → 갭 크기, SET 전압 → SET 속도 파라미터 |
| | **RESET 스윕을 0.01–0.02 V 계단으로 잰 것** (가능하면) | RESET 직전 I-V의 휘어짐으로 필라멘트 온도를 뽑는데, 0.1 V 계단이면 점이 몇 개 안 됨 |
| | 머무는 시간(램프 속도)을 2–3가지로 바꾼 RESET | 열 용해 활성화 에너지 (Kissinger 분석) |
| | 온도별 LRS 저항 (예: 300–400 K, 0.1 V 읽기) | 필라멘트 저항 온도 계수 α. 없으면 문헌값을 쓰지만 정확도가 떨어짐 |
| | 셀 크기별 LRS 저항 | 필라멘트가 하나인지 여러 개인지, 밀도 |

## 왜 필요한가 (방법 요약)

- Russo et al. (IEEE TED 2009, 186–192)의 방법을 따른다. 저항 온도 계수 α로 RESET 직전 R(V)에서 필라멘트 최고 온도를 구한다. 그 온도와 전력으로 RESET 임계 온도와 열저항 Rth를 구한다.
- 필라멘트가 N개 병렬이어도 Rth/R는 N과 무관하다. 그래서 2차원 모델로 이 비율에서 필라멘트 굵기를 정하고, 저항에서 개수를 정한다.
- HRS 저항으로 갭 크기를 정한다. 다만 갭의 반경과 길이를 함께 정할 수는 없어서 "유효 갭"으로 보고한다.
- 산화막 비저항은 포밍 전 누설 전류에서 정한다.
- 램프 속도와 전류 제한을 실험과 같게 놓고 RESET·SET 전압을 맞추면 속도 파라미터가 정해진다.
