## 4. 모델 설계 평가 (요약)

잘 된 점
- RESET(Russo [R])은 식 (1)–(5)를 2차원으로 충실하게 구현. 자기 가속 RESET, 가운데부터 가늘어짐, 램프 속도 의존 방향이 논문과 같음.
- 유한체적 조립(조화 평균 컨덕턴스, 면 소산 G·ΔV²로 줄 발열 = I·V 보존), 열 행렬 분해 재사용, 직렬 저항·CC·C_P 회로 풀이가 깔끔함.
- 파이썬·TS 이중 구현과 정답지 테스트 27개, 가정 58개를 근거와 함께 기록.

약한 점 (중요한 순)
1. **HRS가 격자에 따라 달라짐.** 끊긴 구간이 늘 1–2칸이라 HRS가 칸 크기에 비례. NiO(A35)뿐 아니라 우리 소자도 같음: nz 20 / 40 / 80 → HRS 714 / 523 / 388 kΩ (V_reset 0.49 V는 그대로). 프리셋 HRS(523 kΩ)가 실측(640 kΩ)과 비슷한 것은 우연이고, 그마저 산화막 비저항을 실측보다 10⁸배 낮게 둔 상태의 값. → **후속:** 갭 호핑을 켠 RESET에서는 격자에 수렴 (40–160칸에서 0.57–0.64 MΩ, A55·A61). 호핑 켠 SET은 A60 때문에 아직 못 씀.
2. **SET 식의 물리적 근거가 약함.** bipolar HfOx용 전계 구동 성장식([D] 식 (2))을 unipolar 열 용해 모델에 붙임(CLAUDE.md 지침대로). 전계 0에서도 자라고(A49), 실측 V_set에 맞춘 E_a가 권장 범위 밖(A54), NiO 기본값에서 V_set < V_reset(보통 unipolar와 반대).
3. **우리 소자 프리셋이 실측과 맞지 않음.** 지름 5 nm 가정이라 LRS 약 3.3 kΩ, RESET 0.49 V / 0.10 mA (실측 55 Ω, 1.15 V / 17.8 mA). 측정 데이터 모드는 지름 78 nm + κ_el 보정으로 맞추지만, κ_el이 문헌값 밖이라 모르는 요인을 몰아넣은 유효값.
4. **온도 상한이 없음.** C_P 방전 9900 K, 호핑 갭 5500 K, 펄스 RESET 2000 K. 녹는점·증발·열전도도 온도 의존이 없어 이 영역의 결과는 해석하기 어려움. → **후속:** 산화막 녹는점에서 자름 (A59).
5. **6 nm에서 연속체 가정의 한계.** 길이 방향 칸 0.15 nm, 성장 단위 0.25 nm로 원자 간격보다 작음.
6. **속도 파라미터 역산이 잘 정해지지 않음.** 가상 측정 검증에서도 E_d 17%, v_D0 89배 차이(`inverse.ipynb` 6절). 실측은 램프 속도가 하나뿐이고 머무는 시간도 몰라 E_d를 정할 수 없음.
